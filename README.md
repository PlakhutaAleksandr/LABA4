# Домашнее задание к работе 4

## Условие задач

Чтобы открыть портал, необходимо зажечь три древних кристалла. Кристалл загорается, если переданная ему энергия (A, B, C) кратна трем. Портал откроется только если загорятся все три кристалла. Запишите условие открытия портала.

## 1. Алгоритм и блок-схема.

### Алгоритм

1. **Начало**
2. **Объявление и инициализация переменных:**
   - `int A = 0` — энергия первого кристалла.
   - `int B = 0` — энергия второго кристалла.
   - `int C = 0` — энергия третьего кристалла.
   - `int portal_open = 0` — статус портала (0 — закрыт, 1 — открыт).
3. **Ввод исходных данных:**
   - Вывести заголовок и приглашение ко вводу.
   - Считать значения `A`, `B` и `C` с помощью функции `scanf`.
4. **Вычисления:**
   - Проверить кратна ли энергия каждого кристалла тройке с помощью логического выражения: `portal_open = (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0);`.
5. **Вывод результатов:**
   - Вывести заголовок результатов.
   - Вывести статус открытия портала (`0` или `1`).
6. **Конец**

## 2. Реализация программы

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
#include <stdlib.h>

int main() {
    setlocale(LC_ALL, "Russian");

    int A = 0;
    int B = 0;
    int C = 0;
    int portal_open = 0;

    printf("=== ОТКРЫТИЕ ПОРТАЛА ===\n");
    printf("Введите энергию для трех кристаллов (A, B, C через пробел): ");
    scanf("%d %d %d", &A, &B, &C);

    portal_open = (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0);

    printf("\n--- РЕЗУЛЬТАТЫ ---\n");
    printf("Портал открыт (1 - да, 0 - нет): %d\n", portal_open);

    return 0;
}
